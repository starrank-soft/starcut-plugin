# Reference Video Replication

Use this entry to route the user's request into the existing reference workflow.
Preserve the reference's actions, framing, shot order, pacing, captions, graphics
and sound except for the changes the user requests. Creative restructuring
requires the user's direction; changing the subject alone does not imply it.

## Resolve the Source and Requested Stage

Use the attached video or the identified original master in the current StarCut
project. Reuse confirmed observations, approved reference images and saved build
records for that source. Inspect only missing information that affects the next
action. If the source or replacement target remains ambiguous, ask a focused
question rather than choosing an unrelated asset or inventing product claims.

Selecting this entry chooses a workflow; the message determines the deliverable:
analysis, an adaptation plan, master preparation, variant production or resume.
A plan request does not start paid generation. A production request continues
the authorized work without adding a separate blanket approval step.

## Apply the Existing Workflow

Reuse guidance already loaded in this task; otherwise load it as follows.

- For analysis alone, load `reference-analysis` and answer from actual visual
  and time-located evidence.
- For a plan, editable master or variant, load `reference-adaptation`. It owns
  master reconstruction, segment planning, snapshot checks, replacement
  references, generation, build/resume and acceptance. Follow its current
  rules instead of inventing another execution path. Load `reference-analysis`
  only when the required observations are missing.
- Follow those skills' routing to `media-gen`, `timeline-editing`,
  `transcription` and `graphics` as needed. Keep captions and graphics editable
  when reconstruction requires them. `story-video` is a separate creation
  workflow; do not impose its duration or shot preset on a reference.

After loading guidance, take the next concrete action in the same turn. Reuse
an existing build when resuming. Report blockers and preserve completed work;
do not present a failed generation as pending or repeatedly schedule it.

Deliver the requested analysis or plan, or the resulting Timeline location and
checks performed. Distinguish structural checks from visual acceptance and name
any unresolved differences rather than promising exact replication.
